Створи повноцінний web-додаток (SaaS) для управління готельно-ресторанним комплексом (HMS / PMS), який підтримує мульти-об’єктність (multi-property system).

Мета: створити продукт, який можна продавати іншим готелям.

⸻

🏗️ 1. АРХІТЕКТУРА
	•	Multi-tenant система (кожен готель = окрема організація)
	•	Кожна організація має:
	•	свої об’єкти (готель, будинки, SPA, басейн)
	•	своїх користувачів
	•	свої бронювання
	•	свої налаштування

Технології:
	•	Frontend: React (Next.js)
	•	Backend: Node.js (Express або tRPC)
	•	Database: PostgreSQL
	•	ORM: Prisma
	•	Auth: JWT + roles
	•	Deployment: Replit native
	•	API-first структура

⸻

👤 2. РОЛІ КОРИСТУВАЧІВ

Реалізуй ролі: Super Admin (власник SaaS) Owner (власник готелю) Manager Reception Housekeeping 
Ролі мають різні права доступу:
	•	Reception: шахматка, бронювання, платежі
	•	Manager: тарифи, звіти
	•	Owner: фінанси, аналітика
	•	Super Admin: всі готелі

⸻

🏨 3. СТРУКТУРА ОБʼЄКТІВ (ГНУЧКА)

Система має підтримувати різні типи юнітів:
	•	Room (номер)
	•	House (будинок)
	•	SPA unit
	•	Pool seat / lounger
	•	Bungalow
	•	Any custom rentable unit

Кожен юніт має:
	•	назву
	•	категорію
	•	місткість
	•	статус (active / inactive / maintenance)
	•	календар доступності

⸻
