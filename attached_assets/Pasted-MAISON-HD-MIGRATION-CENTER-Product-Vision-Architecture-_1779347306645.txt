MAISON HD — MIGRATION CENTER
Product Vision + Architecture + Logic + Development Prompt

========================================================
PRODUCT IDEA
========================================================

MaisonHD Migration Center is a dedicated migration operating system inside MaisonHD Finance.

Its purpose is to migrate businesses from BAS / 1C / Excel / Poster / Servio and other legacy systems into MaisonHD without:
- data loss,
- business downtime,
- accounting corruption,
- operational chaos.

Core promise:

“Switch to MaisonHD safely, without stopping your business.”

This is NOT a file importer.
This is a guided migration ecosystem with:
- connectors,
- scanning,
- mapping,
- validation,
- reconciliation,
- rollback,
- parallel run,
- go-live control.

========================================================
PRODUCT PHILOSOPHY
========================================================

The system must feel:
- simple,
- calm,
- premium,
- trustworthy,
- guided.

Users should never feel:
- technical overload,
- accounting fear,
- migration anxiety.

The migration process should feel like:
“Apple setup experience for ERP migration.”

The user flow must be:
1. Connect old system
2. Scan data
3. Review issues
4. Fix critical problems
5. Run trial migration
6. Compare results
7. Run systems in parallel
8. Switch to MaisonHD

========================================================
4. MIGRATION HEALTH SCORE
========================================================

0–50%
Data corrupted / unsafe

51–80%
Migration possible but requires cleaning

81–95%
Almost ready

96–100%
Safe to migrate

Health Score must consider:
- missing fields
- duplicates
- invalid accounting entries
- broken references
- unmapped accounts
- missing tax rules
- invalid balances
