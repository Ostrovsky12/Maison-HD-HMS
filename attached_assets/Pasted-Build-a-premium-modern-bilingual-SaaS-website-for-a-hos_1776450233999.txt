Build a premium, modern, bilingual SaaS website for a hospitality software product called “Maison HD”.

PROJECT GOAL
Create a high-end, conversion-focused website for Maison HD — an AI-powered hospitality operating system.
The result must feel like a real premium SaaS product, not a template or startup landing page.

CRITICAL REQUIREMENT: BILINGUAL SUPPORT
The website MUST support two languages:
- English (default)
- Ukrainian

IMPLEMENTATION REQUIREMENTS:
- Add a language switcher in the top navigation (EN / UA)
- All content must exist in both languages
- Use a clean translation structure (JSON or object-based)
- Do NOT hardcode text directly in components
- Make it easy to scale to more languages later

Example structure:
{
  en: { ... },
  ua: { ... }
}

Switching language must instantly update UI text across the site.
